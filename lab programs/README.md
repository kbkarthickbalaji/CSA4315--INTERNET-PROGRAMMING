## 📌 Repository Overview
This repository contains the complete, production-ready laboratory assignments and analytical experiments for the **CSA4303 – Internet Programming** course. All **46 experiments** are organized in exact ascending numerical order from `01` to `46`.

Each experiment is 100% self-contained with its own:
- `index.html` (Accessible structure with top navigation bar)
- `style.css` (Clean, responsive layout and modern styling)
- `script.js` (Interactive client-side JavaScript validations and calculations)

In addition, the repository features a centralized **Master Interactive Hub (`index.html`)** at the root allowing 1-click execution and real-time search filtering across all 46 laboratory programs.

## 🌐 Live Execution via GitHub Pages
To view and run all 46 experiments live directly in your browser:
1. Go to repository **Settings** &rarr; **Pages** (under Code and automation).
2. Under **Build and deployment** &rarr; **Branch**, select `main` and root `/` (or `/(root)`).
3. Click **Save**.
4. GitHub will publish a live web portal at: `https://kbkarthickbalaji.github.io/<repo-name>/`
5. Faculty can click any experiment to run it live in the browser!

## 💻 How to Run Locally

### Option 1: Master Interactive Hub
1. Clone or download this repository:
   ```bash
   git clone <repo-url>
   ```
2. Double-click `index.html` in the root folder (or run `launch_hub.bat` on Windows).
3. The interactive web dashboard opens with real-time search and unit filtering.

### Option 2: Run Individual Experiments
Navigate directly to any experiment folder (e.g., `01_Library_Management/` or `46_Tax_and_Phone_Bill/`) and double-click its `index.html`. Every experiment runs locally in any web browser without server setup.
